# Virtual Screening & Deep Learning Project

Ce projet explore l'application de l'apprentissage profond (Deep Learning) pour automatiser et améliorer les processus de Virtual Scrining et l'analyse de données complexes, avec un focus particulier sur l'optimisation des performances.

## 📋 Description
Le projet intègre des techniques de traitement de données intensives pour le Virtual Scrining, en utilisant des modèles spécialisés pour améliorer l'efficacité des processus de recherche.

## 🛠️ Contenu du Dépôt
* **`VIRTUAL_SCREENING.mp4`** : Vidéo de démonstration du processus de screening.
* **`active-compounds.csv`** : Jeu de données utilisé pour les analyses.
* **`code_final.py`** : Script principal implémentant la logique d'apprentissage profond.
* **`codecuda.py`** : Script optimisé pour le calcul sur GPU.
* **`memoire_BENADJAL_FINAL (1).pdf`** : Rapport de recherche complet détaillant la problématique, la conception et les résultats.
* **`requirements.txt`** : Liste des dépendances nécessaires pour exécuter le projet.

 
## ⚙️ Prérequis
Pour exécuter les scripts, assurez-vous d'avoir un environnement Python configuré avec les bibliothèques listées dans `requirements.txt`.Le script `codecuda.py` nécessite un environnement compatible GPU.

```bash
pip install -r requirements.txt
